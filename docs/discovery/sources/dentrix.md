Gestionar integralmente clínicas dentales con una suite madura de módulos clínicos, administrativos y de imaging.

## Usuarios objetivo

Clínicas dentales de Estados Unidos; prácticas consolidadas.

## Features detectadas

- Suite integral de gestión dental.
- Módulos clínicos, administrativos y de imágenes.
- Ecosistema de productos y servicios asociados.
