# Open Dental

- **URL**: https://opendental.com
- **Fecha de investigación**: 2026-11-21

## Problema que resuelve

Gestionar la operación completa de una clínica dental con software altamente configurable y una arquitectura abierta a integraciones.

## Usuarios objetivo

Clínicas dentales de Estados Unidos principalmente; prácticas que necesitan personalización profunda.

## Features detectadas

- Gestión clínica y administrativa completa.
- Alto nivel de configuración.
- Cientos de bridges/integraciones disponibles.
- Módulos de imágenes, Web Forms, Patient Portal y recordatorios por email.
- Versión de prueba gratuita.

## Pricing

Soporte mensual USD 199 por mes por ubicación (contrato de 12 meses), que incluye software, soporte telefónico y actualizaciones. Para prácticas fuera de EE. UU. aplican tarifas distintas (ver página de fees).

## Posicionamiento

Software dental de código abierto/configurable, con fuerte comunidad y ecosistema de integraciones.

## Diferenciadores

Configurabilidad extrema y ecosistema de bridges; modelo de soporte mensual por ubicación.

## Notas del investigador

Referencia internacional de profundidad clínica y extensibilidad. Su modelo on-premise y sus fees en USD lo alejan del mercado argentino de consultorios chicos.
