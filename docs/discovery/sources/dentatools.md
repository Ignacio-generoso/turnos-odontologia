# Dentatools

- **URL**: https://dentatools.co/ar
- **Fecha de investigación**: 2026-11-21

## Problema que resuelve

Gestionar clínicas odontológicas con una plataforma cloud sin límite de usuarios, orientada a equipos que crecen.

## Usuarios objetivo

Clínicas odontológicas de Argentina y Latinoamérica; equipos con varios profesionales y usuarios administrativos.

## Features detectadas

- Agenda compartida y auto-agendado de turnos por enlace público.
- Recordatorios por WhatsApp en un clic (arma el mensaje; envío manual, no API automática).
- Historia clínica digital, odontograma interactivo, fotos, radiografías y documentos.
- Cobros y presupuestos en pesos argentinos (PDF).
- Usuarios ilimitados (odontólogos y personal administrativo) en el plan publicado.
- Operación cloud.

## Pricing

ARS $76.500/mes (IVA incluido), con usuarios ilimitados.

## Posicionamiento

Software odontológico cloud con precio único y usuarios ilimitados, apuntando a clínicas que no quieren pagar por asiento.

## Diferenciadores

Usuarios ilimitados por un precio plano, a diferencia de modelos por profesional o por módulo.

## Notas del investigador

Pricing público y comparable. Verificar qué incluye el plan (módulos clínicos, WhatsApp, facturación) y si hay costos adicionales.
