# Dentalink

- **URL**: https://www.softwaredentalink.com/ar
- **Fecha de investigación**: 2026-11-21

## Problema que resuelve

Centralizar la operación de clínicas odontológicas (agenda, ficha clínica, presupuestos y administración) en un software en la nube pensado para Latinoamérica.

## Usuarios objetivo

Clínicas y consultorios odontológicos de Latinoamérica, incluida Argentina; perfiles de dueño, odontólogo y recepción.

## Features detectadas

- Agenda y gestión de turnos.
- Ficha clínica odontológica.
- Presupuestos y gestión administrativa.
- Operación en la nube.
- Certificación ISO 27001 mencionada por el proveedor.
